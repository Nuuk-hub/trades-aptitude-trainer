Trades Aptitude Trainer

An independent educational web application developed by [Nuuk](https://github.com/Nuuk-hub) with AI assistance.

[Open the trainer](https://nuuk-hub.github.io/trades-aptitude-trainer/)

- 400 practice questions across verbal, mechanical, numerical and technical skills.
- Practice with explanations and mistake review, plus timed exam simulations.
- 766 vocabulary words and phrases with Russian translations, English meanings and pronunciation.
- Browser-based progress saving, with no registration required.
- Responsive layout for tablets, phones and computers.

The project was created to support a family member’s preparation and improved through feedback from use.

This project is not affiliated with any employer or testing provider and does not reproduce actual recruitment test questions.
